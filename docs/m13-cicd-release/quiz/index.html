CI/CD & Release Engineering — Quiz

Your release pipeline runs an agent to analyze each candidate. The runner is ephemeral, holds shared registry and cloud credentials in environment variables, and executes dependencies you did not all write. What authority model should the agent's identity have here?

You invoke the agent with claude -p --output-format json. The returned envelope has is_error set to true. Your gate reads .verdict from a schema-constrained result. What is the correct exit handling?

The lesson says: hermetic (--bare) for judging, project-aware for building. Why must the pipeline's release-analysis gate run --bare rather than with full project context?

Northstar enforces separation of duties so the agent that proposes a change is not the agent that approves it. Which mechanisms make this enforcement STRUCTURAL rather than a matter of instruction? (Select all that apply.)

During an incident, an operator points the agent at a 2024 health-verification runbook (owned by Platform, noting an endpoint 'added in v0.8.0') and asks it to fix the readiness probe. The agent proposes pointing the probe at /api/v1/status, citing the runbook. The app's source serves /healthz, /readyz, /api/v1/info — no /api/v1/status. What is the correct discipline?

After the reconciler deploys a canary, the agent reads: error_rate 0.037, p95_latency_ms 640, ready_replicas 1 of 2 desired. SLOs are error_rate <= 0.01 and p95 <= 300 ms. What verdict, and what does the agent do next?

A pipeline step needs a cloud credential to push an image. Why does the module prefer OIDC federation over storing a long-lived cloud key as a CI secret?

Why does the module run the agent headless (claude -p) with --output-format json rather than as an interactive session, for a pipeline stage?

The lesson calls the release pipeline a bonded courier chain with four roles. Which role does the agent play when it reads the diff, Terraform plan, and rendered manifest and signs an approve/block report?

The pipeline wraps the agent call with the shell's timeout N and, when driving Claude via the Agent SDK, sets maxTurns. Why bound the stage two ways?

In the canary stage the agent scrapes signals but the promote/rollback action is taken by a human or the reconciler. Some signals are missing (the scrape returned no p95). What should the fail-closed verdict be?

You define a --json-schema release-verdict object with verdict, blockers, and evidence fields. The agent returns valid JSON, but it omits the blockers field the schema marks required. How should the gate treat this run?
