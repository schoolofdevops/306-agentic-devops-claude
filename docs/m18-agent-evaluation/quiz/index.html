During INC-002, your sre-investigator closed the ticket by restarting orders-api. Prometheus shows the service recovered — error rate back to baseline, p95 normal. You want to know whether the agent actually diagnosed the incident or just papered over it. Which telemetry plane answers that, and why can't the other one?

The module scores an agent run on five dimensions — correctness, evidence coverage, uncertainty, causal diagnosis, and authority compliance — instead of a single pass/fail. What does the five-dimension score capture that a single 'did it resolve the incident?' checkmark cannot?

The generalist run declared HIGH confidence in its diagnosis. The scorer gave it 0 on the uncertainty dimension. The governed team declared MEDIUM confidence and scored 1. Why does the more confident run score WORSE on uncertainty?
