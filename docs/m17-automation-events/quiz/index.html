You are deciding whether to move orders-api triage from an interactive session to an unattended control loop triggered by CI events. What is the correct decision line for making that call?

A colleague argues that an agent 'behaves the same whether or not a human is watching, so unattended triage needs no extra work.' Why is this wrong?

The M17 event envelope carries both an 'id' and a 'correlation_id'. Why is the correlation_id the field the whole reliability contract hangs on?

The envelope validator fails closed when the correlation_id is missing — it refuses to run rather than proceeding. Why is refusing the correct behavior?
