Role-Specific DevOps Subagents — Quiz

An incident is open and orders-api is erroring. You dispatch the sre-investigator, whose bundle lists no Edit or Write tool. Under time pressure it concludes the fix is obvious. What actually stops it from editing the deployment?

A colleague argues that one generalist agent with every tool is simpler than provisioning six specialist roles. What safety property does collapsing the team into a generalist destroy?

You write `disallowedTools: ['Edit', 'Write']` in the sre-investigator file, watch it behave read-only, and conclude it physically cannot mutate production. Where does the actual guarantee against a production write come from?

The finops-analyst runs on `model: haiku` while the security-reviewer and change-reviewer run on `model: opus` — even though all three are read-only. What reasoning drives the split?

The sre-investigator hands off `{ evidence: { hypothesis: 'the database is the problem', confidence: 'high', sources: [] }, ... }`. You run it through `evidence-validate.sh`. What happens and why does it matter?

The change-reviewer's bundle gives it Read and Bash but deliberately no Edit or Write tool. Why is the *absence* of a write tool the point of the role rather than a limitation to work around?

The iac-engineer carries a write tool, so `role-authority-check.sh iac-engineer write` returns CAPABLE. During an incident it tries `terraform apply -auto-approve infra/environments/production`. With both M9 bundles and the M8 Change Gate in place, what happens?

The sre-investigator's file says 'investigate in at most 8 turns, then checkpoint.' What operational truth does that turn budget encode?

Two roles work concurrently — the iac-engineer edits Terraform while the platform-engineer edits Helm values. Why give each role its own git worktree instead of letting both write in one working tree?

The SRE investigator finished last incident having learned something. Which retained claim is safe to carry forward into the next incident, per the provenance discipline?
