Agentic IaC and FinOps — Quiz

Why do you write the module's `CLAUDE.md` spec yourself, rather than asking the agent to write it?

The agent reads your spec and replies that the task is 'bounded' before writing any code. What does that tell you?

You write a failing `terraform test` before the module has any code, and watch it fail with 'Unsupported argument' errors. Why is that failure the right thing to see at this point?

The house style skill requires every physical resource name to be built as `"${var.project}-${var.environment}-<role>"` instead of typed out directly. What problem does this prevent?

`storage_encrypted = true` and `publicly_accessible = false` are hardcoded in the module rather than exposed as variables a caller could set. Why does the style skill treat making them variables as the mistake?

You build this module inside a git worktree, with permission prompts turned off. What does the worktree specifically give you that makes turning the prompts off safe?

An agent authored a Terraform change and you want it to confirm the change is correct against production. Which operation can it run freely there, and which is gated?

In the four-reviewer chain, why does the FinOps analyst run on Haiku while the security reviewer and change reviewer run on Opus?

You ask the agent to disable encryption and make the database public, and it refuses well, citing your own spec file. Then you make the exact same change yourself with a text edit, and the security scanner blocks it. What does this pair of results show?

You turn off two separate safety settings by hand. The scanner reports only one of them, even though both values are sitting right there in the plan JSON. What does this tell you?

Why is the IaC engineer the only role in the chain that carries a write tool, with the other three reviewers having none?

A single agent-generated change passes `terraform validate`, but replaces the orders database, resizes it 16x, and opens Postgres to `0.0.0.0/0`. Which statements about how the review handles it are correct? (Select all that apply.)
